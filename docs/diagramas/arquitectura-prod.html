SIGMETUM-A · INFRA · PROD

Arquitectura de producción

ALB + auto scaling 1–3 · HTTPS con ACM · DNS Route53 · Cognito para el login · eu-west-3

Login (Hosted UI, código + PKCE): el navegador sale a Cognito, vuelve a /auth/callback con un código y lo canjea en /oauth2/token. Envía el token de acceso (RS256) al backend como Bearer, y el backend lo verifica con las claves públicas JWKS del pool (iss, token_use=access, exp).

Configuración: el backend recibe COGNITO_USER_POOL_ID por variable de entorno; Amplify recibe VITE_COGNITO_DOMAIN y VITE_COGNITO_CLIENT_ID solo en la rama. Transición: el login antiguo (POST /log con JWT_SECRET) sigue activo y se retira al final.

Prod: el pool tiene protección contra borrado y las URLs de retorno son sigmetum-a.org y www.sigmetum-a.org.
